# Example Knowledge Kits

A set of Knowledge Kits that serve as examples for the various knowledge kit concepts and also provide some basic tutorials on using knowledge graphs. Check out the readme's included with the kits. 

Here is how you would install one of these kits on your endpoint: 

```bash
$ kits install -t my_endpoint starwars
```

For more information on setting up endpoints in your environment, see the main readme.
